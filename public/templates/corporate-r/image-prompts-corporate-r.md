# corporate-r 최종 이미지 생성 프롬프트

## 생성·저장 규칙

- 대상: `public/templates/corporate-r/assets`의 JPG 35장
- 생성 방식: 아래 항목을 순서대로 **한 번에 한 장씩** 생성
- 결과 규격: **1600×1000px, 가로 16:10, JPG, sRGB**
- 저장 방식: 각 항목의 제목과 정확히 같은 파일명으로 덮어쓰기
- 용도: NEXHARBOR 항만·물류 기업 포트폴리오 웹사이트
- 기준 스타일: `photorealistic-natural`, 실제 한국 항만·물류 현장을 풀프레임 카메라로 촬영한 기업 다큐멘터리 사진
- 공통 색감: 딥 틸·네이비·스틸 그레이를 기본으로 하고, 일출·일몰 장면에만 절제된 골드 하이라이트 사용
- 공통 질감: 실제 금속, 콘크리트, 바닷물, 유리, 목재의 미세한 질감과 자연스러운 대기 원근
- 크롭 대응: `object-fit: cover`로 잘려도 핵심 피사체가 남도록 중요 요소는 중앙 60% 안에 배치하고, 화면 가장자리에는 잘려도 되는 배경을 둔다.
- 모바일 대응: 사람 얼굴, 장비의 핵심 연결부, 선박의 선수·사일로 등 식별 요소를 화면 끝에 붙이지 않는다.
- 금지: 이미지 안의 글자, 회사명, 상표, 실제 기업 로고, 선박명, 숫자, 번호판, 간판, 워터마크, UI, 프레임, 포스터 문구
- 품질 금지: 과도한 HDR, 네온 미래도시, 게임 렌더, 플라스틱 CG 질감, 복제된 사람·차량·컨테이너, 휘어진 크레인, 끊어진 와이어, 비정상 손, 잘못된 PPE, 위험한 작업 자세
- 인물 지침: 한국인 성인, 자연스러운 업무 표정과 자세, 현장 인물은 안전모·반사조끼·안전화 등 올바른 보호구 착용

> 각 프롬프트는 공통 조건을 포함해 그대로 사용한다. 생성 후 리사이즈로 맞추지 말고 처음부터 1600×1000으로 생성한다.

## 생성 후 검수 체크리스트

1. 파일이 정확히 35개이며 파일명이 위 제목과 일치하는지 확인
2. 모든 파일이 JPG, 1600×1000, sRGB인지 확인
3. 글자·로고·숫자·선박명·번호판·워터마크가 생성되지 않았는지 확인

6. 유사 장면끼리 구도와 시간대가 반복되지 않는지 확인
7. 기존 `photo-map-corporate-r.txt`는 수정하지 않고 동일 파일명으로만 교체
