Artist Statement

이 영역에는 작가님의 작가 노트가 들어갑니다. 작업의 출발점이 된 경험, 다루는 재료와 방법, 반복되는 형상이나 색이 무엇을 향하고 있는지를 담습니다.

문단은 필요한 만큼 늘리거나 줄일 수 있습니다. 문장이 길어져도 읽기 편하도록 본문 폭과 행간을 잡아 두었습니다.

전달해 주신 글을 그대로 옮겨 넣어도 되고, 메모 수준으로 보내주시면 홈페이지에 맞게 정리해 드립니다.

작업 과정을 설명하는 문단, 관람객에게 건네고 싶은 말로 마무리하는 문단처럼 구성을 나눠 두면 읽는 흐름이 자연스러워집니다.

Statement — English

This block holds the English version of the artist statement. Galleries, art fairs, and overseas collectors often ask for one, so the layout keeps a bilingual pair by default.

Paragraph length and count are flexible. If only a Korean statement is available, this block can be removed and the page still reads well.

Send the text in any form — a finished statement or rough notes — and it will be arranged to fit the page.
