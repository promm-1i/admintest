할로베일

NANO CERAMIC WINDOW TINT

새로운 세라믹 융합 기술을 담은 Haloveil® 나노 세라믹 윈도우 썬팅 필름은

햇빛과 열을 알맞게 조절해 차의 연비를 돕고 피부 건강을 지켜 주는 것은 물론, 또렷한 시야로 쾌적한 운전을 약속드립니다.

LUNA Ceramic Tint

Luna는 성능과 스타일을 모두 챙기면서도 가장 합리적인 비용으로 시공할 수 있습니다.

지금 가장 만족스러운 필름 Luna를 만나 보세요.

Learn more

LUNA S Ceramic Tint

Luna S는 기존 Luna 의 품질을 한층 단단하게 끌어올린 업그레이드 제품입니다.

Haloveil® 의 스테디셀러 Luna의 눈부신 진화, Luna S를 경험해 보세요.

Learn more

SILVA Ceramic Tint

Silva 필름은 태양열 조절 기능에 더해 맑은 숲속에 와 있는 것처럼 시원한 시야를 열어 줍니다.

수입차 전용 에디션 등급으로 선보였던 Silva에 대해 더 알아보세요.

Learn more

RIVE Ceramic Tint

Rive의 묵직하고 감각적인 블루블랙 컬러는 차에 깊이 있는 역동성을 더해 줍니다.

모든 농도에서 고르게 80%의 태양열 차단 성능을 내는 Rive의 또 다른 장점을 찾아보세요.

Learn more

SAHARA Ceramic Tint

사막의 뜨거운 햇살을 견디는 이름처럼 Sahara는 강렬한 볕 아래에서도 중후한 멋을 지키는 필름입니다.

이 필름의 또 다른 매력을 알아보세요.

Learn more

CLEAR W Ceramic Tint

Clear W는 뛰어난 에너지 효율성과 어디에나 어울리는 감성을 지녔습니다.

운전의 즐거움을 더해 주는 Clear W를 만나 보세요.

Learn more

EDGE X Ceramic Tint

최상위 등급 썬팅 필름인 Edge X는 한여름 무더위에도 차 실내 온도를 최고 섭씨 13도까지 낮춰 줍니다.

강력한 열 차단 성능 외에도 더 많은 Edge X만의 장점을 알아보세요.

Learn more

SHADOW Ceramic Tint

Shadow는 태양열을 지금껏 없던 수준으로 차단하는 최고의 성능을 자랑합니다.

완벽에 가장 가까운 필름. Shadow에 대해서 더 알아보세요.

Learn more
