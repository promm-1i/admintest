Phone

Get it on Google Play
  1. 1Install Bymirror from Google PlayIf touch does not work, open Google Play in your PC browser, find Bymirror, choose install and select that phone. It installs when the phone is online.

Connect

  1. 1Plug the phone into the PC with a USB cableA charging-only cable will not connect.
  2. 2If the PC asks to install a USB driver, install it and approve the Windows promptOnce per phone. File transfer for this phone stops on this PC; you can restore it in settings and help. Leave the cable connected during setup. Unplug and reconnect it if asked.
  3. 3Connect in the PC window, then allow the prompts on the phoneIf touch does not work, use the PC permission-assist button only while an allow prompt is visible on the phone. Check both the USB and screen-sharing prompts, pressing again if needed.
  4. 4When the phone screen appears, use the mouseIf it is locked, enter your own PIN or pattern with the mouse and keyboard.

Help

The PC says the phone was disconnected

The cable may be loose or screen sharing may have stopped. Check the cable and reconnect in the PC window.

When do I use permission assist?

Use it when a USB or screen-sharing permission prompt is visible on the phone and you cannot tap it. The PC presses allow once. Without a prompt, it could tap somewhere else on the phone.

Another program is using the phone connection

A program such as Android development tools has the connection. Close that program and reconnect.

Phone file transfer no longer works on this PC

The first connection changed the USB driver for Bymirror. In settings and help, restore the USB driver, then unplug and reconnect the cable to use file transfer again.

Using Bymirror with other MintCL apps such as Bypad or Bycam

One program per phone at a time. If another program is using it, switch that phone to Bymirror in that program.

Where do my photos go?

They are copied only to the PC folder you choose. They are not sent over the internet or to the operator’s server. Privacy policy
