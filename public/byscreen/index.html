시작하기

처음 한 번만 하면 됩니다. 문의 답장에 "3번을 보세요"라고 하면 이 번호입니다.

PC

PC 프로그램 받기윈도우 10(2004 이상)·11, 64비트 · 압축 파일 53MB
  1. 1압축을 풀고 byscreen-host.exe 실행압축 푼 폴더는 지우지 마세요. 새 화면을 만드는 드라이버 파일이 같이 들어 있습니다.
  2. 2"Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행아직 코드 서명을 하지 않은 프로그램이라 처음 한 번 뜹니다.
  3. 3방화벽 창이 뜨면 허용와이파이로 쓸 때 필요합니다. USB로만 쓸 거면 취소해도 됩니다.
  4. 4트레이 아이콘 → 태블릿에 보여줄 화면 → 새 화면으로 늘리기 (확장) · 준비하기관리자 확인 창에서 예를 누릅니다. PC마다 처음 한 번입니다. 프로그램은 창 없이 화면 오른쪽 아래 트레이에만 있습니다.

태블릿

Google Play에서 받기안드로이드 8 이상
  1. 1Google Play에서 바이스크린 설치
  2. 2USB로 쓸 거면 USB 디버깅 켜기설정 → 태블릿 정보 → 소프트웨어 정보에서 빌드 번호를 7번 누르면 개발자 옵션이 생깁니다. 설정 → 개발자 옵션 → USB 디버깅을 켭니다.

USB로 연결

  1. 1태블릿을 USB 케이블로 PC에 꽂기
  2. 2PC에 "USB로 연결된 기기가 있어요"가 뜨면 연결
  3. 3"USB 드라이버를 한 번 설치해야 해요"가 뜨면 설치 → 예태블릿마다 처음 한 번입니다.
  4. 4태블릿에 바이스크린을 열지 묻는 창에서 '항상'에 체크하고 확인

와이파이로 연결

  1. 1태블릿 앱에서 와이파이를 고르고 PC 선택같은 공유기에 있는 PC가 목록에 나옵니다.
  2. 2연결을 누르고 PC에 뜨는 확인 창에서 허용태블릿마다 처음 한 번입니다.

도움말

앱에 "USB 디버깅을 켜 주세요"가 나와요

PC 프로그램이 태블릿을 케이블 모드로 바꿀 때 USB 디버깅을 씁니다. 태블릿 2번을 따라 켜 주세요.

케이블을 꽂아도 아무 일이 없어요

충전 전용 케이블이면 연결되지 않습니다. 데이터가 되는 USB-C 케이블로 바꿔 보세요. PC 프로그램이 트레이에 켜져 있는지도 확인해 주세요.

회사 PC에서 관리자 비밀번호를 물어요

처음 두 번(새 화면 준비, USB 드라이버 설치)은 관리자 권한이 있어야 넘어갑니다. 회사 IT 담당자에게 요청해 주세요. 그 뒤로는 묻지 않습니다.

문제를 알려 주고 싶어요

탐색기 주소창에 %LOCALAPPDATA%\Byscreen을 치면 나오는 host.log 파일을 메일로 보내 주세요. 태블릿 기종과 무슨 일이 있었는지가 이 파일에 남습니다.
