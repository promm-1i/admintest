노을 인테리어 디자인

노을 인테리어 디자인은
공간의 쓰임과 가족 구성, 평소 생활 습관을 먼저 여쭙고,
가족마다 다른 수납과 동선을 도면에 먼저 그려 봅니다.

여러 공간을 지어 온 경험과 믿음

목공 · 타일 · 도장 반장이 현장마다 같은 사람으로 들어가 마감을 맞춥니다.

20평대 구축부터 90평 테라스 하우스까지 직접 설계하고 시공했습니다.

  • PROJECT 1

    가람 라온 하늘마루 골든베이

    2025

    이번 프로젝트는 톤온톤 색과 간결한 선으로 정리한 45평 모던 아파트 인테리어로,
    욕실과 주방, 드레스룸까지 똑같은 재질감과 간접 조명으로 이어 문을 열어 두면 한 공간처럼 보입니다.
    수납장은 손잡이 없는 푸시 도어로 벽 안에 짜 넣어 벽처럼 보이게 했으며,
    안방은 호텔 스위트룸처럼 침실과 욕실을 한 줄로 이어 두었습니다.

    Location
    서울특별시 마포구 상암동
    Size
    45py
    Keyword
    Ivory
  • PROJECT 2

    다온 더 플래티넘

    2025

    이번 프로젝트는 미니멀리즘을 바탕으로 디자인한 33평 아파트로, 거실에는 패브릭 소파와 원목 테이블만 두었습니다.
    몰딩과 장식 선반을 빼고 수납은 벽 안으로 넣어, 눈에 걸리는 물건 없이 바닥과 벽이 넓게 드러납니다.
    벽과 바닥을 중간 톤 한 가지로 맞춰, 창으로 들어온 햇빛이 방 안쪽까지 고르게 퍼집니다

    Location
    서울특별시 성동구
    Size
    33py
    Keyword
    Modern
  • PROJECT 3

    해솔 힐사이드 파크

    2025

    이번 프로젝트는 흰색 바탕에 짙은 목재를 포인트로 써서 깔끔하면서도 톤이 고르게 정돈된 주거 인테리어입니다.
    갈색 계열 마감재는 자칫 낡은 느낌을 줄 수 있지만 절제한 마감 계획으로 정돈된 모습을 지켰습니다.
    꼭 필요하지 않은 가벽은 줄이고 선을 정리해 보기에 넓고 편안한 느낌을 더했습니다.

    Location
    서울특별시 성동구
    Size
    40py
