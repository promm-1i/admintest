Get started

You only do this once. When a reply says "see step 3", it means these numbers.

PC

Get the PC programWindows 10 or 11, 64-bit · 51 MB zip
  1. 1Unzip and run bypen-host.exeIt has no window; it sits as the Bypen icon in the notification area at the bottom right. Keep the unzipped folder.
  2. 2If "Windows protected your PC" appears, More info → Run anywayThe program isn't code-signed yet, so this shows once.
  3. 3With several monitors, pick one from the icon's menuThe blank pad covers the monitor you pick there.

Tablet

Get it on Google PlayAndroid 8 or later
  1. 1Install Bypen from Google Play
  2. 2Turn on USB debuggingSettings → About tablet → Software information: tap Build number 7 times to get Developer options. Then Settings → Developer options → USB debugging.
  3. 3On the app's home, pick a mode: drawing on the PC's screen, or the blank pad

Connect with USB

  1. 1Plug the tablet into the PC with a USB cable
  2. 2When the PC says a USB device is connected, press Connect
  3. 3When it asks to install the USB driver once, press Install → YesOnce per tablet.
  4. 4When the tablet asks to open Bypen, tick Always and press OKThen open your drawing app on the PC and draw on the tablet.

Help

The drawing app ignores pressure

Set the app's pen input to Windows Ink. After the 3-day trial, the pen draws at one width until you buy pressure. Also check that Pen pressure is on in the app's menu.

The app says to turn on USB debugging

The PC program uses USB debugging to switch the tablet into cable mode. Follow Tablet step 2.

The pen doesn't draw on the PC

On the lock screen the pen lands on the lock screen; unlock the PC. Windows also blocks the pen over programs run as administrator; start that program normally.

Nothing happens when I plug the cable in

Charge-only cables don't connect. Try a USB-C cable that carries data, and check that the PC program is running in the notification area.

A work PC asks for an administrator password

Installing the USB driver the first time needs administrator rights. Ask your IT team; it won't ask again after that.

I want to report a problem

Type %LOCALAPPDATA%\Bypen into File Explorer's address bar and email us the host.log file there. It records what happened.
