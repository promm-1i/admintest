# 프리미엄 디자인 업종 라벨 대응표

최종 수정: 2026-09-21

## 주의

- 디자인 코드 앞자리(`HOSP`, `RENP` 등)는 처음 만들 때 붙은 것이라 지금 업종과 다를 수 있다. 묶음은 코드가 아니라 `industryKey` 를 따른다.
- 같은 코드를 다른 시안이 넘겨받는 일이 있다. 라벨을 고칠 때는 `industry` 문구를 함께 확인한다.
