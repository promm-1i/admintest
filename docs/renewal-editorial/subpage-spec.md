# 서브페이지 원본 대응표와 실측값

최종 측정: 2026-09-20  
검증 도구: `tools/ref-clone/audit_woori_sub.mjs`  
기준 원본: `spot.wooribank.com` 은행소개 영역 (하위 56개 코드를 수집해 골격을 분류)

## 1. 원본 서브페이지 골격 유형

56개 페이지를 수집해 실측한 결과 골격은 다섯 가지다.

| 유형 | 구조 | 원본 예 |
|---|---|---|
| A. hero 소개형 | `page-info` + `hero.type-single`(200vh) + `contents`/`section` | 비전/가치체계, 조직 소개, CEO 소개, 인재개발제도, 우리윤리경영, 사회공헌활동 |
| A2. hero 다단형 | `page-info` + `hero.type-multi`(200vh) + `contents` | ESG경영 |
| B. hero 없는 소개형 | `page-info` + `contents`/`section` | CI/캐릭터 소개, 우리핫라인 |
| C. 목록형(선형) | `page-info` + `contents` + `board-util` + `board-list` + `pagination` | 보도자료, 공고, 재무제표 |
| C2. 목록형(카드) | `page-info` + `contents` + `videos-list` 3열 그리드 | 미디어광고 |
| D. 상세형 | `contents` + `section` + `article.detail` | 보도자료 상세 |

원본은 같은 유형 안에서도 제목 크기가 쪽마다 다르다. 예를 들어 섹션 제목이 사회공헌활동은 56px/500, 인재개발제도는 56px/700, 비전/가치체계는 24px/600이다. NOVERIQ는 유형마다 기준 쪽을 하나씩 고정해 그 값을 따른다.

## 4. 검증 결과

`node tools/ref-clone/audit_woori_sub.mjs` 기준 18개 경로 × 3해상도 = 54건.

| 항목 | 결과 |
|---|---|
| 일치 | 54 |
| 차이 | 0 |
| 허용 오차 | 2px |

비교 항목은 `page-info`, `hero` 6개 요소, `contents`, `section`, 섹션 제목, 목록·카드·페이지네이션·상세 블록의 x·폭·높이·글꼴·굵기·행간·자간·여백이다. 세로 위치는 문구 길이가 달라 비교하지 않는다. 이 검사는 골격 검사이며 본문 요소 전수 비교가 아니다.

## 5. 의도적 차이

- 우리은행 사진 대신 임시 이미지 슬롯
- 우리은행 문구 대신 NOVERIQ 문구
- 항목 수는 NOVERIQ 실제 데이터 기준 (템플릿, 사례, 공지, FAQ)
- 카드에는 원본과 같이 썸네일과 제목 한 줄만 둔다. 디자인 코드는 상세 쪽으로 옮겼다
