IntersectionObserver는 원본과 같이 진입과 아래쪽 완전 이탈에서 클래스를 바꾼다. `tomorrow` observer는 `(min-width: 1024px)`에서만 연결하며, 그보다 좁은 화면에서는 `init/active` 클래스를 모두 제거하고 정적 세로 카드 흐름을 사용한다.
