# 당근 카페 글쓰기

당근 카페 **홈페이지 제작소**(`cafe.daangn.com/hompeiji-jejags`)에 포트폴리오 글을 올리는 도구.

## 쓰는 순서

```
python serve.py https://cafe.daangn.com/hompeiji-jejags   # 창 띄우고 살려 둔다 (CDP 9222)
python write.py                                            # 포트폴리오 글 채우기
python notice.py                                           # 공지 글 채우기 (대표 사진 20장)
python verify.py                                           # 사진과 아래 글이 짝 맞는지 그림으로 대조
```

`serve.py` 는 창을 띄운 채로 계속 떠 있어야 한다. 나머지는 CDP 로 붙어서 조작한다.

## 규칙

- **로그인은 사람이 한다.** 비밀번호·인증번호는 스크립트가 넣지 않는다. 처음 한 번만 직접 로그인하면 `~/.daangn/profile` 에 남는다.
- **등록 버튼은 누르지 않는다.** 공개되는 글이라 사람이 확인하고 올린다.
- **문구에 영업·광고를 넣지 않는다.** 2026-09-28 당근에서 주의 받았다. 문의 유도("편하게 문의주세요", "댓글이나 채팅 주세요"), 서비스 제안("홈페이지 제작해드립니다"), 가격, 사이트 주소 전부 금지. `<업종> 홈페이지 제작 사례입니다` + 화면에 실제로 있는 기능 서술 + "이렇게 구현하면 이쁩니다" 까지만.

## 함정

- 한 글에 사진 **20장까지**.
- 사진을 한꺼번에 던지면 **업로드가 끝난 순서대로 꽂혀 순서가 뒤섞인다.** 한 장씩 올리고 `.ProseMirror img` 개수가 늘어난 걸 확인한 뒤 다음 장.
- 올라간 사진은 파일명이 서버 UUID 로 바뀐다. 순서 검증은 편집기 안 이미지를 하나씩 찍어 **원본과 그림 대조**해야 한다(`verify.py`).
- 본문은 ProseMirror 다. **문단 사이는 Enter, 문단 안 줄바꿈은 Shift+Enter.** 빈 줄을 Enter 로 넣으면 빈 문단이 끼어 간격이 크게 벌어진다.
- 세션 폴더(`~/.daangn/profile`)는 **저장소에 넣지 않는다.** 이 저장소는 공개다.
