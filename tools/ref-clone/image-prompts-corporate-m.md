# corporate-m 이미지 생성 프롬프트

## 공통 스타일

모든 이미지는 한국의 첨단 산업설비 기업을 위한 프리미엄 B2B 기업 홈페이지 사진으로 제작한다. 실제 현장에서 촬영한 듯한 포토리얼리즘, 절제된 청색과 차콜 톤, 깨끗한 금속 재질, 자연스러운 산업 조명, 과도한 HDR이나 인위적인 네온 효과 없이 정교하고 신뢰감 있는 분위기. 화면 안에는 문자, 숫자, 간판, 브랜드 로고, 워터마크를 넣지 않는다. 기존 기업이나 제품을 식별할 수 있는 상표도 노출하지 않는다.

공통 제외 요소: 일러스트, 3D 렌더 느낌, 플라스틱 같은 재질, 과장된 미래 도시, 비현실적인 배관 구조, 읽을 수 있는 글자, 로고, 워터마크, 왜곡된 손, 중복된 사람, 과포화 색상, 과도한 빛 번짐, 저해상도, 흐릿한 피사체.

## 생성·적용 체크

1. 지정한 픽셀 크기로 각각 한 장씩 생성한다.
2. 자동 확대나 콜라주 대신 독립된 단일 이미지를 사용한다.
3. 문자·로고·워터마크가 없는지 원본 크기로 확인한다.
4. PC와 모바일에서 `object-fit: cover` 크롭 시 핵심 피사체가 유지되는지 확인한다.
5. 파일명은 위 표기와 정확히 동일하게 저장한다.
