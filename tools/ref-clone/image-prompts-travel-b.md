# travel-b 이미지 생성 프롬프트

대상 템플릿: `public/templates/travel-b/`

생성 원칙:

- 아래 이미지는 한 장씩 생성하고 `public/templates/travel-b/assets/`에 표기된 파일명 그대로 덮어쓴다.
- 표기된 픽셀 크기와 가로세로 비율을 바꾸지 않는다.
- 사진 안에 글자, 숫자, 로고, 표지판 문구, 워터마크, 브랜드 마크를 넣지 않는다.
- 실제 한국 산악·하천 지형을 촬영한 듯한 다큐멘터리 사진 질감, 자연광, 과도한 HDR·CG 질감·플라스틱 질감 금지.
- 인물이 필요한 장면은 비식별 뒷모습 또는 원거리 실루엣만 사용한다.
- 전체 시리즈는 짙은 청록, 암회색 암석, 자연스러운 초록을 중심으로 통일한다.
