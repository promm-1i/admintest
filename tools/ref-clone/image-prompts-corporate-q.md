## 생성 대상에서 제외한 코드형 요소

다음 요소는 사진 슬롯이 아니라 HTML/CSS로 유지해야 하는 정보·장식 요소다. 이미지로 생성하지 않는다.

- 서브페이지 상단의 궤도 원형 장식
- 로고·CI 마크와 협력기관 명칭
- R&D 서비스 아이콘과 바로가기 아이콘
- 조직도, 비전 다이어그램, 프로세스, 표, 차트, 검색·게시판 UI
- `mini-visual` 75px 장식 패턴
- 지도상의 실제 주소·좌표·도로명 텍스트
- 버튼, 탭, 슬라이드 페이지 표시와 모든 본문 글자

`photo-map-corporate-q.txt`는 이 문서와 별개로 취급하며, 이미지 생성 단계에서 임의로 만들거나 수정하지 않는다.
