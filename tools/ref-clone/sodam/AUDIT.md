원본과 다르게 둔 것
- 치료 전후 · 감량 수치 · 후기는 실제 자료가 없어 '예시' 문구를 붙였다 (허위 실적 금지). 0201 전후 카드는 원본처럼 누르면 로그인 창.
- 0304 탭 3 · 4(과민성 대장 · 갱년기)는 원본 부품 구성을 따르되 내용은 새로 씀.
- 1차에서 만든 추정 부품(아코디언 · 궤도 · 핫스팟 · 아치 등)은 더 이상 쓰지 않아 sub.css 에서 뺐다(515 규칙).
