# 크몽 포트폴리오 등록

크몽 포트폴리오 등록 화면(`kmong.com` 전문가 > 포트폴리오)에 대표 1:1 + 상세 10장을 올리는 도구.
당근 도구(`tools/daangn`)와 같은 구조 — 창을 띄워 살려 두고 CDP 로 붙어서 조작한다.

## 쓰는 순서

```
python serve.py                 # 창 띄우고 살려 둔다 (CDP 9223). 처음 한 번 직접 로그인
python probe.py                 # 등록 화면의 칸·선택지를 읽어 form.json 에 적어 둔다
python fill.py <코드>            # 제목·설명·업종·이미지까지 채운다 (등록 버튼은 안 누름)
```

## 규칙

- **로그인은 사람이 한다.** 비밀번호·인증번호는 스크립트가 넣지 않는다. 세션은 `~/.kmong/profile` 에 남는다.
- **등록 버튼은 누르지 않는다.** 사람이 확인하고 올린다.
- **가격·사이트 주소·외부 연락처를 넣지 않는다.** 크몽 정책이고, 템플릿 푸터에 실제 연락처가 있어
  캡처도 푸터 위에서 자른다([[project-promo-cards]]).
- 올린 뒤 **승인 대기**가 걸린다. 당근처럼 바로 노출되지 않는다.

## 이미지

`Desktop\개발\크몽_업로드\<코드>_<브랜드>\`
- `00_대표_1x1.png` 1080×1080 (크몽: 1:1 · 가로 600 이상)
- `01~10_상세.png` 가로 1000 · 세로 3000 이하 (크몽: 가로 600 이상 · 세로 3000 이하)

만드는 건 `tools/promo-cards/kmong_shots.py`.

## 함정 (당근에서 겪은 것 — 여기도 같을 것으로 보고 확인할 것)

- 사진을 한꺼번에 던지면 업로드가 끝난 순서대로 꽂혀 **순서가 뒤섞인다.** 한 장씩 올리고
  미리보기 수가 늘어난 걸 확인한 뒤 다음 장.
- 세션 폴더(`~/.kmong/profile`)는 **저장소에 넣지 않는다.** 이 저장소는 공개다.
